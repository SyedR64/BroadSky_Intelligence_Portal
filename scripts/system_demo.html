Light · default

Every component, light.

The off-white canvas, ink type and the orange-to-violet accent from the landing page. Company accents appear only on bars, dots and rules.

Dark · portal console and theater

The same components, dark.

Set data-sys-theme="dark" on the html element for a whole page, or on any section for a dark band. Type, spacing, radii and accents do not change.

Copy safety net

No identifiers reach the reader.

Frame.humanize rewrites visible text after the frame mounts and again whenever a page renders new content. Code, keyboard keys and anything marked data-raw stay untouched.

What the renderer wrote

Four lines that leak dataset keys, a file name, an agent code, a missing value and a failed number. The frame rewrites them in place before anyone sees them.

What the reader sees

Rule: renderers should still write plain English; humanize is the net, not the plan. Inline code and anything marked data-raw stay as written.
