        07 · Build vs buy

        Buy the plumbing. Build the judgment that only BSP has.

        Classified by each agent's vendor or build path. Analyst guidance, not company decisions.

        Decision rules

        1. Buy when the agent lives inside the system of record. If ServiceTitan, Procore or Gorgias ships it natively, speed beats differentiation; a buyer will not pay more for a home-built dispatch board.
        2. Build when the agent's memory is BSP data. Bid go or no-go on CET's New England bid radar, weather surge on Punctual Pros' storm history, grant signals from NIH RePORTER, docket tracking: that scoring is the IP that makes an OS an OS at exit.
        3. Hybrid by default for documents. Buy extraction or transport (Conexiom, Vic.ai, Intapp), build the exception queue, disclosure and audit layer once and reuse it across companies.
        4. Every purchase passes the vendor AI review (control 5). A 30-day pilot against the company's own baseline, SOC 2 Type II, no training on portfolio data, and an exit and export clause.
        5. Never single-source the model. Route small models to extraction and frontier models to drafting; keep a second provider qualified for failover (control 4).

        Source: Portfolio AI-agent plan, vendor or build path per agent, Oct 2026.

        08 · By company

        Each OS, its agents, its plan

        Why this page

        Design and program rationale

        An operating partner should be able to approve a wave in one meeting, and a buyer should see the controls behind the value.

        One system, not a feature dump

        Give every agent the same anatomy: trigger, agent, approver. Forty-five then scan as one system.

        KPI: time to approve a wave; agents stopped vs shipped per quarter.

        Controls up front

        Show the controls, owners and evidence before anyone asks for them.

        KPI: diligence questions answered from the page; tier-3 incidents (target 0).

        Lead with the number

        One headline figure, with its cost and risk-adjusted net beside it. Every figure stays an estimate until measured.

        KPI: share of the $12.7M ceiling re-based on measured baselines; capacity value counted only with a hiring plan.

        Institutional tone, sources on every claim

        Sober type and a source on every claim. It should read as a memo, not a pitch.

        KPI: agents backed by an effect from a comparable deployment (target 45 of 45 via pilots).

        Approve wave 1, measure for 90 days.

        Six agents, controls 1–5 live everywhere, and a day-90 review against 8-week baselines. Track it in the portal's tech-enablement module.
