    03 · Reusable patterns

    04 · Rollout waves

    Four waves over 18 months, lowest risk first.

    Inbound-contact and document agents go first because they have the clearest baselines. Finance follows, then revenue agents, then monitoring services that can be sold as recurring revenue. Each wave has a gate. Thomas Scientific is sequenced to its December 2027 loan maturity.

        07 · Build vs buy

        Buy the plumbing. Build the judgment that only Broad Sky has.

        Classification below is derived from each agent's named vendor or build path. The rules are the PRG's analyst guidance, not company decisions.

        Decision rules

        1. Buy when the agent lives inside the system of record. If ServiceTitan, Procore or Gorgias ships it natively, speed beats differentiation; a buyer will not pay more for a home-built dispatch board.
        2. Build when the agent's memory is Broad Sky data. Bid go/no-go on CET's New England bid radar, weather surge on Punctual Pros' storm history, grant signals from NIH RePORTER, docket tracking: that scoring is the IP that makes an OS an OS at exit.
        3. Hybrid by default for documents. Buy extraction or transport (Conexiom, Vic.ai, Intapp), build the exception queue, disclosure and audit layer once at PRG level and reuse it across companies.
        4. Every purchase passes the vendor AI review (control 5). 30-day pilot against the company's own baseline, SOC 2 Type II, no training on portfolio data, exit/export clause.
        5. Never single-source the model. Route small models to extraction and frontier models to drafting; keep a second provider qualified for failover (control 4).

        Why this page

        Design and program rationale

        Written for Tyler and the PRG. The page has one job: make 45 agents legible enough that an operating partner can approve a wave in one meeting, and a buyer's diligence team can see the controls behind the value.

        Linear — the system, not a feature dump

        Borrowed: numbered sections and an agent panel shown as product, with every item using the same anatomy (trigger → agent → approver).

        Does: turns 45 agents into one system a PRG partner can scan in minutes.

        KPI: time-to-approve a wave; agents killed vs shipped per quarter.

        Vanta Trust Center — controls up front

        Borrowed: a visible, checkable controls list with owners and evidence links.

        Does: answers the security and legal questionnaire (ABA 512, TCPA, EU AI Act) before an AM Law client or an exit buyer asks.

        KPI: diligence questions answered from the page; Tier-3 incidents (target 0).

        Ramp — lead with the number

        Borrowed: a single headline figure in the hero, backed by a working product below it.

        Does: frames the program as EBITDA, not experimentation, puts the cost and the risk-adjusted net next to the ceiling, and keeps every figure labelled est. until re-based on an 8-week baseline.

        KPI: share of the $12.7M ceiling re-based on measured baselines; capacity value counted only with a hiring plan.

        Hebbia — institutional AI for finance

        Borrowed: sober type, the inspector detail panel and sources on every claim.

        Does: reads as a value-creation memo, not a vendor pitch, which is what a Smith + Howard-style exit narrative needs.

        KPI: agents backed by an effect from a comparable deployment (target 45 of 45 via pilots).
